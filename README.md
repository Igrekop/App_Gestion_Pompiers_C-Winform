<!-- ABOUT THE PROJECT -->
## À propos du projet

Cette application WinForms permet de gérer :

- Les effectifs des pompiers
- Les interventions en cours et passées
- Le matériel et les véhicules
- La planification des équipes

L'objectif est de simplifier la gestion administrative et opérationnelle des casernes de pompiers.

<!-- GETTING STARTED -->
## Pour commencer

Pour exécuter l'application localement, suis ces étapes.

### Prérequis

* Windows 10 ou supérieur
* Visual Studio avec support WinForms et .NET Desktop Development

### Installation

1. Clone le dépôt
   ```sh
   git clone https://github.com/Igrekop/Gestion-Pompiers-WinForms.git
   ```

2. Ouvre le fichier solution `.sln` dans Visual Studio

3. Compile et lance le projet (`F5` ou `Ctrl+F5`)

# Ou alternativement exécuter simplement le raccourci :
```sh
  SAE_POMPIER_A21 - Shortcut.lnk
```

## Utilisation

* Ajouter, modifier ou supprimer des pompiers dans la base de données

* Suivre les interventions en temps réel

* Gérer le matériel et les véhicules

* Planifier les équipes pour chaque intervention
